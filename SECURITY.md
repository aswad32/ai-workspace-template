# Security Policy

## Supported Versions

Security fixes are considered for the latest version on the repository's
default branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability-reporting option from the repository's **Security** tab,
or contact the repository maintainer through a private channel listed on their
GitHub profile.

Include a concise description, affected files or workflow, reproduction steps,
impact, and any suggested mitigation. Do not include secrets or private data.
