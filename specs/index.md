# SDD Package Index

Maintain one row per package. `/close-spec` owns terminal status updates. Do not
remove completed, superseded, or abandoned packages; they are change history.

## Status Rules

- Active: `Draft`, `Ready`, `In Progress`, or `Implemented`.
- Terminal: `Done`, `Superseded`, or `Abandoned`.
- Terminal packages are immutable except for factual metadata corrections and
  reciprocal supersession links.
